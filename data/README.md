# Data

This directory documents the data layer used by the procurement analytics platform.

## Data Policy

The original project uses enterprise procurement data. No proprietary, confidential, or personally identifiable data is included in this repository.

For portfolio purposes, this directory is reserved for:

- Synthetic datasets
- Sample datasets
- Data dictionaries
- Source-to-target mappings
- Data format documentation

## Expected Data Flow

Source System
→ Bronze
→ Silver
→ Warehouse / Gold
→ Power BI

## Example Data Domains

The platform can contain procurement-related domains such as:

- Purchase orders
- Requisitions
- Consumption
- Items
- Suppliers
- Categories
- Contracts
- Exchange rates
- Organizational dimensions
